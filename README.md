# PRODIGY_CS_04
Simple Keylogger ⌨️A project completed for the Cyber Security Internship at Prodigy InfoTech.📝 Project Overview this repository contains a basic Python-based keylogger. A keylogger is a program that records every keystroke made by a user on a keyboard. This tool is designed to capture keystrokes and save them sequentially into a local text file (keylog.txt). It demonstrates how input monitoring works on desktop operating systems.✨ Features continuous Monitoring: Listens to keyboard input in the background.Readable Output: Formats special keys (like Space and Enter) so the log file is easy to read.Local Storage: Automatically appends captured data to a local keylog.txt file in real-time.🛠️ Prerequisites this script requires Python and the pynput library.Note: This script is designed for desktop operating systems (Windows, macOS, Linux). It will not function on mobile environments like Android due to OS-level sandboxing and security restrictions.Install the required library using pip:
bash:
pip install pynput

Download or clone the repository to your local machine.Run the script in your terminal:
python keylogger.py
Type anywhere on your computer.Press Ctrl + C in the terminal to stop the program.Open the newly generated keylog.txt file to view the recorded keystrokes.⚠️ Ethical & Legal Disclaimer this tool is strictly for educational purposes and ethical hacking practice.Keyloggers are dual-use technologies. Unauthorized use of a keylogger to capture passwords, personal data, or private conversations without explicit consent is illegal and a severe violation of privacy.Do not deploy this software on any system you do not own.Do not use this software without the express, written permission of the device owner.
